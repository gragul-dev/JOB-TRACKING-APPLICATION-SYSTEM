A comprehensive, frontend-driven Job Tracking Application designed to help you organize, visualize, and manage your job hunt. Built with React and TypeScript, it provides intuitive dashboards, Kanban boards, and analytics to keep your career goals on track.

## ✨ Features

- **📋 Kanban Board View:** Drag and drop your job applications seamlessly across different stages (e.g., Applied, Interviewing, Offer).
- **📊 Analytics & Metrics:** Gain visual insights into your application success rates and overall progress with a dedicated metrics dashboard.
- **📅 Interview Tracking:** Keep tabs on upcoming interviews, schedules, and past performance.
- **📑 Applications Table:** A detailed tabular view to sort, filter, and manage all your job prospects.
- **🕒 Activity Sidebar:** Track recent changes and updates to your job hunt journey in real-time.
- **⚡ Blazing Fast:** Powered by Vite for rapid development and an optimized user experience.

## 🛠️ Tech Stack

- **Frontend Framework:** React 18+
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** CSS / UI Components
